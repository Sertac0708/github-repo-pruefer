# My projects (template)

Copy this file to `~/.claude/repo-pruefer/projects.md` and fill it in.
It stays private on your machine — the skill reads it to tell you, for every reviewed repo,
which of your projects it fits. The more concrete the "Open issues", the better the suggestions.
